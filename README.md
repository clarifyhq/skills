# Clarify Skills

Agent skills for working with [Clarify](https://clarify.ai) - the AI-native CRM.

## Available Skills

### clarify-api

Guidelines for working with the Clarify CRM API - includes authentication, endpoints, pagination, filtering, and CRUD operations for records.

## Installation

Install using the skills CLI:

```bash
npx skills add clarifyhq/skills
```

Or install a specific skill:

```bash
npx skills add clarifyhq/skills --skill clarify-api
```

## Supported Agents

- Claude Code
- Cursor
- Cline
- Codex
- And other agents that support the Agent Skills specification
